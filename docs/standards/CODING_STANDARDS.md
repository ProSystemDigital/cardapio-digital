# Padrões de Código

| Campo | Definição |
| --- | --- |
| Status | Em evolução |
| Aplicação | Projetos da ProSystem Digital |

## Objetivo

Estabelecer uma referência comum para legibilidade, consistência,
manutenibilidade e revisão do código produzido pela ProSystem Digital.

## Escopo

Este documento abrangerá convenções de implementação, organização, nomes,
tipagem, tratamento de erros, testes, revisão e práticas específicas das
tecnologias oficialmente adotadas.

## Consolidação futura

A versão completa será consolidada futuramente a partir dos padrões validados
nos projetos, sem antecipar regras que ainda não tenham maturidade ou aplicação
consistente. Até essa consolidação, prevalecem o HKA FIELD, a configuração
versionada e as convenções existentes em cada repositório.
